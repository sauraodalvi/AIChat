Instructions for Pushing C:\git_projects\chat to GitHub

Follow these steps to push your code to GitHub:

Step 1: Open Command Prompt

Open a Command Prompt window by pressing Win + R, typing cmd, and pressing Enter.

Step 2: Navigate to your project directory

cd C:\git_projects\chat

Step 3: Initialize Git repository

git init

Step 4: Add all files to Git

git add .

Step 5: Commit your changes

git commit -m "Initial commit"

Step 6: Add the remote repository

git remote add origin git@github.com:sauraodalvi/VeloraChat.git

Step 7: Rename the branch to main

git branch -M main

Step 8: Push to GitHub

git push -u origin main

If you encounter any issues with SSH authentication, you might need to use HTTPS instead:

git remote add origin https://github.com/sauraodalvi/VeloraChat.git

Or if you've already added the remote, you can change it:

git remote set-url origin https://github.com/sauraodalvi/VeloraChat.git
